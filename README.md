# 方言で出身地当て(仮称)

方言・地域の生活知識についての質問に答えていくと、出身地(言語形成期を過ごした地域)を都道府県から県内の地域まで推定する Web ゲームです。静的サイトとして GitHub Pages で公開する予定です。

現在はフェーズ0(雛形)で、ゲーム本体はまだありません。

## 特徴(予定)

- ベイズ推定で絞り込むので、数問の誤答があっても正解に戻れます。
- 進行役のキャラクターが、その時点の最有力地域の方言で喋ります。
- 推定の途中経過を地図のヒートマップで見せます。

質問文はすべて自作です。

## 開発

Node.js 24 以上が必要です。

```
npm install
npm run dev        # 開発サーバー
npm test           # 単体テスト
npm run build      # 型チェックと本番ビルド(dist/)
npm run licenses   # LICENSES.md とクレジット画面用データを再生成
```

## 地理データ

地域の基本単位(セル)は二次医療圏です(335)。`data/geo/` の成果物はコミット済みなので、通常は作り直す必要はありません。

```
npm run geo:fetch  # 元データを data/raw/ に取得(約1.2GB、コミットしない)
npm run geo:build  # cells.json / municipalities.json / japan.topo.json を生成
```

| ファイル | 内容 |
| --- | --- |
| `data/geo/cells.json` | セルの id・名称・都道府県コード・代表点・人口、都道府県の一覧 |
| `data/geo/municipalities.json` | 市区町村とセルの対応表(人口付き) |
| `data/geo/japan.topo.json` | 簡略化した地図(レイヤー:`cells`、`prefs`) |

- 境界と二次医療圏の構成は国土数値情報 医療圏データの2020年度版、人口は令和2年国勢調査によります。2024年度からの第8次医療計画で見直された医療圏は反映していません。
- セルの代表点は、構成市区町村の重心を人口で重み付けして平均した点です(面積の重心ではなく、人が住んでいる側に寄ります)。
- 地図では 3 km² 未満の島を省略しています。人口などのデータからは省いていません。
- 簡略化の強さなどは `scripts/geo/build.ts` の `GEO_CONFIG` で変えられます。

## 構成

| 場所 | 内容 |
| --- | --- |
| `site.config.json` | リポジトリ名(Vite の base)と表示タイトル。リポジトリ名を変えるときはここだけ直す |
| `data/licenses.yaml` | 権利情報の唯一の元データ。LICENSES.md とアプリ内クレジットの両方をここから生成する |
| `data/questions/` | 質問データ(フェーズ3) |
| `data/host/` | 進行役の台詞(フェーズ4) |
| `scripts/` | データ加工・生成スクリプト |
| `scripts/import-gaj/` | 国語研データ取り込みの枠(未実装。データは同梱しない) |
| `src/` | アプリ本体 |
| `tests/` | 単体テスト(vitest) |

## データを追加するときの決まり

- 配布ページを実際に開いて、ライセンス・クレジット表記・取得日を確認してから `data/licenses.yaml` に書く。記憶や推測で書かない。
- 確認できないデータは同梱しない。CC BY-NC など非営利限定のデータは使わない。
- npm パッケージも、依存に加える前にライセンスを確認する。
