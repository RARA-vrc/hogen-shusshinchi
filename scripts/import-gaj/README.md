# scripts/import-gaj(枠のみ)

国立国語研究所の方言データ(方言文法全国地図 全データ、全国方言分布調査など)を、将来このプロジェクトの質問分布に取り込むための変換スクリプトを置く場所です。

**現時点では利用許諾を得ていません。** そのため次を守ります。

- 国語研のデータファイル、およびそこから作った派生物を、このリポジトリに含めない。
- 入力ファイルは `scripts/import-gaj/input/`、出力は `scripts/import-gaj/output/` に置く。どちらも `.gitignore` で除外済み。
- 許諾が得られたら、`data/licenses.yaml` に条件・クレジット表記・取得日を記載してから、変換結果を取り込む。

`convert.ts` は入出力の形だけを決めた未実装の枠です。実行するとその旨を表示して終了します。
