# 回答とコメントの受け口(Google Apps Script)

同意したプレイヤーの回答記録とコメントを、Google スプレッドシートに1行ずつ追記するための受け口です。`site.config.json` の `logEndpoint` が空のあいだは、サイトは何も送信しません。

2026-11-19 にこの手順でデプロイし、コマンドからの送信とブラウザ(本番ビルド)からの送信の両方で、`plays` シートに行が増えることを確認しました。形式の合わない送信が捨てられることも確認しています。

## 保存される内容

| 列 | 内容 |
| --- | --- |
| day | 日付(日単位、UTC) |
| estimate_level / estimate_id | 最初の推定の粒度(region / pref / cell)とその id |
| correct | 正解のセル id、`abroad`、`multiple`、または空(未回答) |
| count | 答えた質問数 |
| questions / answers | 質問 id と選んだ選択肢 id(空白区切り、同じ順番) |
| comment | 任意のコメント(300字まで) |

時刻、IP アドレス、端末の情報は保存しません。

## 手順

1. Google スプレッドシートを新しく作る。
2. メニューの「拡張機能」→「Apps Script」を開き、最初からあるコードを消して `Code.gs` の中身を貼り付け、保存する。
3. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選ぶ。
   - 次のユーザーとして実行:自分
   - アクセスできるユーザー:全員
4. 承認画面で、自分のスプレッドシートへのアクセスを許可する。
5. 表示された「ウェブアプリの URL」(`https://script.google.com/macros/s/…/exec`)を、`site.config.json` の `logEndpoint` に書く。
6. サイトをビルドして公開し直す。

スクリプトを直したときは、「デプロイを管理」から同じデプロイを新しいバージョンに更新します(新しいデプロイを作ると URL が変わります)。

## 知っておくこと

- URL を知っていれば誰でも送信できます。スクリプトは形式の合わない送信を捨て、コメントを300字に切り、5万行で受け付けを止めますが、いたずらの送信を完全には防げません。
- コメントは自由記述です。個人が特定できる内容が書かれていたら、その行を消してください。
- 止めたいときは、`logEndpoint` を空に戻して公開し直すか、Apps Script 側でデプロイをアーカイブします。
